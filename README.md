# README #

### MDC Style ###

This repo contains unofficial CSL (Citation Style Language) files that allow citation managers such as Zotero to produce citations and bibliographies that adhere to the [McMaster Divinity College Press Style Guide](https://mcmasterdivinity.ca/mdcpress/#style-guide). 

The master file (named "MDC-style.csl") supplies a basic format. The annotated bibliography style ("MDC-annotated-bibliography") adds the content of the 'Extra' field following each bibliographic entry. 

### How do I get set up? ###

1. Download the relevant source files (either "MDC-style.csl" or "MDC-annotated-bibliography.csl", or both). 
2. Install the files one at a time so the styles are available in your citation manager (e.g. Zotero). (Please search the web for help with this step, as each application is different.)
3. When generating citations and/or bibliographies using your software, select the appropriate style.
